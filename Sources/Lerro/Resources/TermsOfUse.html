Lerro 使用说明

更新日期：2026 年 8 月 4 日

用途

这是用于本地学习和个人使用的 macOS 应用。请在遵守所在地法律、第三方服务条款和模型许可证的前提下使用。

模型服务

本地模型和用户配置的第三方 API 输出都可能存在错误。涉及医疗、法律、财务或其他重要决策时，请自行核验结果。用户负责所选 Provider 的账户、API Key、费用、配额和服务条款。

数据与备份

数据主要保存在当前设备。API Key 以明文保存在本机 JSON 配置中，也可能进入用户启用的系统备份。用户负责必要的备份和凭据管理，并可通过应用内历史与 Provider 管理功能删除记录。

软件更新

Lerro 通过签名更新清单发现较新版本，并显示应用内下载入口。用户点击后进入下载与安装流程。用户应从 Lerro 官网获取首个公开版本；安装后可在应用内检查更新。更新归档同时受 Apple 代码签名、公证和应用内归档签名验证。

第三方组件

应用使用 Apple 系统框架、MLX Swift LM、Hugging Face 相关库、所选本地模型和用户配置的第三方 API。各组件、模型和服务分别遵循其许可证与服务条款。
