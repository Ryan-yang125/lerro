# Support

Lerro is maintained by one person in maintenance mode. Use the public channels
by request type:

- GitHub Issues for reproducible bugs and scoped feature requests.
- GitHub Discussions for setup and usage questions.
- GitHub Private Vulnerability Reporting for suspected security issues.

Include the Lerro version and build, macOS version, Mac architecture, the
feature involved, expected and observed results, and minimal reproduction steps.
Review logs for personal data before attaching them, and use synthetic text in
screenshots.

Support covers the current stable release. Behavior that depends on the Mac
(permission state, microphone hardware, Speech resources, Accessibility in a
specific editor, global shortcuts, multiple displays, Gatekeeper) may need a
fresh run of the diagnostic steps in
[docs/development.md](docs/development.md#troubleshooting).

Security-sensitive reports follow [SECURITY.md](SECURITY.md); keep the details out
of public issues.
