# Lerro Brand Guidelines

## 品牌核心

- 名称：Lerro
- 发音：`LEH-ro`
- 品类：本地优先的 macOS 语音写作工具
- 承诺：自然表达进入麦克风，清晰文字落到当前光标
- 主标语：`自在说，清楚写。`
- 英文标语：`Speak freely. Write clearly.`
- Campaign：`Let your voice become a sentence.`

## 品牌人格

Lerro 的表达保持温和、精确、安静、自信。产品让用户始终了解当前状态、数据位置
和下一步动作。Apple 原生感来自熟悉的控件、系统语义、空间一致性与细节质量。

## 标志

标志「光标 L」由两个独立图形组成：一根圆角光标立在一条圆角基线上，中间留 6 个单位
的缝。整体读作字母 L，也读作光标停在一行文字上。缝让光标可以单独上色、单独闪烁；
HUD 和菜单栏中的光标就是标志里的光标。

构造（品牌单位）：

| 部件 | 尺寸 |
| --- | --- |
| 光标 | 宽 10，高 46，全圆角 |
| 缝 | 6 |
| 基线 | 宽 36，高 9，全圆角，左端与光标对齐 |
| 整体 | 36 × 61 |
| 32 px 以下 | 光标宽 13，基线高 12，缝 5 |

字标为大写 `Lerro`：首字母 `L` 是标志，`erro` 是 Inter SemiBold 转成路径的轮廓，
间距手工收紧。使用规则见 [`logo-usage.md`](logo-usage.md)。

## 色彩

| 名称 | 值 | 用途 |
| --- | --- | --- |
| 墨黑 `ink` | `#15161A` | App Icon 底板、HUD、深底背景 |
| 纸白 `paper` | `#F6F4EF` | 基线、浅底背景、HUD 文字 |
| 墨水蓝 `inkBlue` | `#2F5BFF` | 光标、浅色外观的主窗口强调色 |
| 深底墨水蓝 `inkBlueOnDark` | `#4A6BFF` | 深色背景上的光标与强调色 |
| 石墨灰 `graphite` | `#8B8C93` | 次要信息 |

- 墨水蓝用于光标和可点击的强调元素，不用于大面积背景。
- success、warning、error 使用系统绿、橙、红。墨水蓝不表达状态。
- 主窗口按钮、选中态、开关、焦点边界使用墨水蓝，在深色外观中使用深底墨水蓝。
- 对比度数值见 [`color-accessibility.md`](color-accessibility.md)。

## 视觉语言

1. **中性内容层**：主窗口的画布、侧边栏、卡片、文字、普通图标、边界与选择背景
   使用 `LerroTheme` 黑白灰 token，并为 Aqua、Dark Aqua 和 Increase Contrast 提供
   对应值。
2. **墨水蓝交互层**：主要行动、选中态、开关和焦点边界使用墨水蓝。
3. **墨黑 HUD**：HUD 是墨黑 Liquid Glass 胶囊，浅色与深色外观一致，内含墨水蓝光标。
4. **内容主导布局**：留白建立层级，卡片只用于独立任务或明确分组。
5. **稳定表面表达层级**：侧边栏、卡片和浮层依靠灰阶、细边界与克制阴影分层。
6. **原生排版**：SF Pro、苹方与 SF Mono 使用 24 / 14 / 13 / 12 pt 四级字号，
   tracking 统一为 `-0.15`。SF Pro 只用于 App UI，Logo 使用轮廓字标。

## 产品 UI tokens

| 角色 | Token | 规范 |
| --- | --- | --- |
| 主文字 | `text` | 浅色 `#292929` |
| 次级文字 | `secondaryText` | 浅色 `#5D5D5D` |
| 低强调文字 | `tertiaryText` | 浅色 `#9E9E9E`，只承载非必要信息 |
| 必要小字 | `metadataText` | 浅色 `#6B6B6B`，满足小字对比要求 |

| 卡片 | icon / radius | 20 / 16 pt |
| 主要 CTA | shape | pill / capsule |
| 强调交互 | color | 墨水蓝，深色外观使用深底墨水蓝 |
| hover | duration | 150 ms ease-out |
| pointer-down | displacement | 向下 1 pt |

## 构图

- 主窗口使用平台导航结构、工具栏和列表层级。
- 页面标题与正文沿同一基线网格对齐。
- 8 pt 基础节奏覆盖间距，4 pt 用于紧密图标与标签。
- 交互控件保持至少 28 × 28 pt 的点击区域，主要动作优先 32–36 pt 高度。
- 导航项使用 14 pt 图标与 8 pt 连续圆角；卡片使用 20 pt 图标与 16 pt 连续圆角。
- 主要 CTA 使用 pill，普通导航与卡片保持稳定轮廓。
- 浮层从触发点或当前工作区域出现，进入与退出沿同一路径。

## 应用范围

| 场景 | 内容 |
| --- | --- |
| App Icon | macOS 26 Icon Composer 分层文件：墨黑底板、墨水蓝光标层、纸白基线层，系统负责裁切、高光和外观变体 |
| 菜单栏 | 18×18 pt template image，八帧，状态依靠形状和动画 |
| 侧栏 | 顶部显示字标，不放图标 |
| 关于页 | App Icon、名称、版本 |
| Onboarding 首屏 | 标志，光标闪烁一次后停住 |
| HUD | 墨黑玻璃胶囊与墨水蓝光标，见 ADR 0013 |
| Ask | 原生浮动面板承载问题、答案、复制与写回动作 |
| 仓库与发布 | 大留白、轮廓字标、真实产品截图 |
